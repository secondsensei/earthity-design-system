Behavior contract
themeRequired modifier: eu-parallax-card--sky. A new artwork is a new --{theme} block setting --eu-parallax-card-bg / -shade (RGB triplets) and the background-image of __sky and both __roll pseudo-elements, with PNGs in assets/parallax-card/{theme}/.
pagingPrev/next wrap around: ((i % n) + n) % n. Hide __nav when there is one entry or none.
keyboard← / → — previous / next entry. Ignore the keys while focus is in an editable field.
announceA visually hidden aria-live="polite" line: "N of M: eyebrow title" after each step.
product shot<img class="eu-parallax-card__product"> inside __card, after __scene. Framing per entry through CSSOM: --eu-parallax-card-fit-w (default 112%), -fit-x, -fit-y (from centre, % of the card). No product yet: render none; the card is complete without it.
crossfadeOn a step, keep the outgoing shot mounted with __product--out, BEFORE the incoming one in source order. Both animations fill both; no timer is needed. Replace the element (don't swap src) so the animation re-runs.
tiltOn pointermove (fine pointers, never under reduced motion): nx, ny = pointer offset from the card centre over its size (−0.5…0.5). Write --eu-parallax-card-mx/-my = nx/ny, -sx/-sy = (n + 0.5) × 100%, -shine = 0.85, and __card transform: rotateX(−ny·14deg) rotateY(nx·14deg). On pointerleave: clear the transform, mx/my/shine back to 0.
shot throwThe shot overhangs the card, so where the card nearly fills the screen the full throw carries the art off the viewport and it is clipped mid-wing. Measure the room beside the card and write --eu-parallax-card-shot-travel (0…1, default 1) — it scales the shot's parallax only; the card's rotation and the plates behind it stay full.
toggleOptional <button class="eu-parallax-card__check" aria-pressed> with an accessible name naming the entry. On false→true set data-locking for 420ms. __check-hint inside it is opt-in, only while unpressed.
motionCloud drift is CSS. prefers-reduced-motion stops drift, transitions, shine, hint and crossfade in CSS; the consumer skips tilt. Set data-motion="gyro" on the block while a phone's attitude steers the tilt.
