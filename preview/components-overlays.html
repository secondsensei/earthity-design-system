DETAILS / DISCLOSURE — <details> (native)

Native expand/collapse. Add open attribute to default-open.

How does corridor authorization work?
A corridor is a pre-approved flight path between two sites. Operators request access during a host's availability window. Authorization is logged in real time and cleared at the end of each window.
What does host onboarding involve?
A site survey, RF clearance check, and integration with your existing physical access controls. Most sites are live within 7 business days.
Who pays for site infrastructure?
earthity provides the relay node hardware free of charge for verified hosts. You retain ownership of the physical site; we operate the autonomy stack.
COMBOBOX — <input list> (native)

Native datalist suggestion behavior. Browsers handle keyboard nav and filtering. Suitable for simple text-completion. Use a spec-only custom combobox for rich rendering.

POPOVER — popover attribute (native, modern browsers)

Native popover via popovertarget. Auto-positioned, click-outside dismissal, no JS. Chrome 114+, Firefox 125+, Safari 17+.

SPEC SHEETS — patterns the system does NOT ship

These have no native HTML primitive that satisfies the design system's behavior expectations. Consumers wire the behavior using a framework primitive (Radix, Headless UI, native framework tabs). The system specifies what they should do, not how.

Tabs (visual ships in components-nav.html; behavior is consumer-wired)

Behavior contract
roleTab list: role="tablist"; tab: role="tab"; panel: role="tabpanel"
selectionActive tab: aria-selected="true" (other tabs "false")
linkEach tab aria-controls="panel-id"; each panel aria-labelledby="tab-id"
tab orderTab key reaches the active tab; Arrow keys move between tabs (no Tab navigation between them).
keyboard←/→ — previous/next tab; Home — first tab; End — last tab; Enter/Space — activate (or auto-activate on focus)
visualUse .eu-tabs + .eu-tab from earthity-components.css; toggle aria-selected attribute

Rich dropdown (selectable list with custom content per option)

Behavior contract
roleTrigger: aria-haspopup="listbox", aria-expanded; menu: role="listbox"; item: role="option"
openingClick, Enter, Space, ArrowDown all open. Focus first option (or selected option if any).
keyboard↑/↓ — move focus between options; Home/End — first/last; Enter — select; Esc — close, restore focus to trigger; Tab — close, move on
visualTrigger: .eu-field eu-select; menu: .eu-popover with options styled as .eu-sidebar__item
positioningBelow trigger by default; flip up if not enough room. Match trigger width.

Custom combobox (typeahead with rich rendering)

Behavior contract
roleWrapper: role="combobox"; input: aria-autocomplete="list", aria-expanded, aria-controls="listbox-id"; menu: role="listbox"
filteringFilter on input change. Highlight matched substring. Show "No matches" if empty.
keyboard↓ opens menu and moves focus to first option; Enter — select; Esc — close; Tab — close + commit value
visualInput: .eu-field; menu: .eu-popover; options: same styling as rich dropdown
